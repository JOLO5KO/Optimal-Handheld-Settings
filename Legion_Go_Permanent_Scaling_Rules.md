# Permanent Legion Go scaling rules

Effective October 5, 2026. Applies to every Legion Go title and all included power profiles.

- AMD Adrenalin GPU Scaling: On.
- AMD Adrenalin Integer Scaling: On.
- AMD Adrenalin Scaling Mode: Full Panel.

These rules supersede conflicting Preserve Aspect Ratio or Integer Scaling Off instructions in earlier libraries and appends. Do not silently disable integer scaling or substitute another scaling mode.

Retain all unrelated permanent rules and existing game settings. Select title-specific resolutions and verify actual output; do not guarantee exact borders, stretching, or border-free fill without verification. Radeon Image Sharpening remains Off by default unless specifically justified.
